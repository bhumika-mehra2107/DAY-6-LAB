**Programme:** BBA Aviation Management

## About

This lab focuses on **privacy risks, PII, data minimisation, safe prompting, and human verification** in aviation.

## Key Topics

* Identifying and removing PII
* Using placeholders such as `[PASSENGER NAME]` and `[BOOKING REFERENCE]`
* Protecting passport, medical, payment and password information
* Creating safe AI prompts
* Classifying information as Public, Internal, Confidential or Restricted
* Data minimisation
* Verifying aviation policies before communication
* Human review of AI-generated content

## Key Learning

Sensitive passenger and employee information should not be unnecessarily shared with AI tools. Placeholders and data minimisation reduce privacy risks. Important information such as baggage status and compensation policies must be verified through authorised systems.

**Main Principle:**
**Protect Personal Data → Use Minimum Information → Verify Information → Human Review**
